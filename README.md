# FreAlgo — personal, ad-free, algorithm-free global news explorer

Pick a country on a globe (or from an accessible list), filter by sector, outlet, language, period
or source orientation, choose the order yourself, and read the original publisher. There are no
ads, no engagement ranking, no infinite scroll and no tracking.

**FreAlgo 2.0** adds five sections around that core:

| Section          | What it is                                                                                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Explore**      | The globe, 2D map and country list (v1), with "about" and "publisher home" kept apart                                                                      |
| **Stories**      | Finite, chronological collections with three reading depths, "Why this story?", and events: reports grouped by shared headline wording, each in Story Mode |
| **Discover**     | Seeded, explained Surprise Me and a daily discovery; optional Story Journeys                                                                               |
| **Perspectives** | One event, outlet by outlet, with label provenance and the gaps in FreAlgo's own sources                                                                   |
| **My World**     | Your explicit choices, stored in your browser, turned into a page you can share                                                                            |

Everything FreAlgo shows is a publisher's own words, a count from its data, or a curated entry
with a named source. Nothing is generated by AI, and nothing is ranked by attention.

## Quick start (one command)

Requirements: Docker Desktop (or Docker Engine with Compose v2).

```bash
docker compose up --build
```

Then open http://localhost:3000. The stack starts PostgreSQL, Redis, a one-shot `migrate` job
(migrations plus idempotent seed), the web app and the ingestion worker. Out of the box the app
shows clearly badged **fixture** data. Real publisher feeds are registered paused until their
terms are reviewed; see [docs/data/source-methodology.md](docs/data/source-methodology.md).

## Local development

Requirements: Node.js 24, Docker.

```bash
cp .env.example .env            # then set SESSION_SECRET / ADMIN_API_TOKEN (openssl rand -base64 48)
npm ci
npm run infra:up                # postgres + redis only
npx prisma migrate deploy
npm run db:seed
npm run dev                     # web on :3000
npm run worker:dev              # ingestion worker (separate terminal)
```

| Command                                                              | What it does                                                        |
| -------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `npm run lint` / `typecheck` / `format:check`                        | Static checks                                                       |
| `npm test`                                                           | Unit tests                                                          |
| `npm run test:integration`                                           | Integration tests against `DATABASE_URL_TEST` (must end in `_test`) |
| `npm run build && npm run test:e2e`                                  | Playwright on Chromium, WebKit and Firefox (desktop + mobile)       |
| `npm run ci`                                                         | Everything CI runs, except e2e                                      |
| `npm run sources:dry-run -- --slug <outlet>`                         | Fetch and parse a real feed without storing anything                |
| `npm run sources:activate -- --slug <outlet> --reviewer … --notes …` | Record a terms review and activate a feed                           |
| `npm run perf:lighthouse` / `perf:globe`                             | Lighthouse and globe frame-time profiles (server running)           |
| `npm run perf:explain` / `perf:load`                                 | Query plans at 200k synthetic articles (test DB) / API load test    |
| `scripts/ops/backup.sh`, `restore-drill.sh`                          | Checksummed backups; backup → restore → compare drill               |
| `scripts/ops/smoke.sh <url>`                                         | Post-deploy smoke test                                              |
| `scripts/ops/observe-scheduler.sh [min]`                             | Watch the real scheduler ingest 3 real feeds into the test DB       |
| `npm run db:retag`                                                   | Re-tag stored articles with the current country/sector/type rules   |
| `node --import tsx scripts/cluster-events.ts [--dry-run]`            | Group recent reports into events (the worker does this hourly)      |
| `node scripts/perf/route-js.mjs <url>`                               | JavaScript per route; confirms the 3D engine loads only on Explore  |

## Feature flags (FreAlgo 2.0)

Each v2 feature can be switched without a rebuild by setting `FEATURE_<NAME>=true|false` (web and
worker) and restarting. The live state is on `/methodology#features` and `/api/v1/methodology`.

| Flag                          | Default    | Feature                                        |
| ----------------------------- | ---------- | ---------------------------------------------- |
| `FEATURE_STORIES`             | on         | Stories                                        |
| `FEATURE_DISCOVER`            | on         | Surprise Me and the daily discovery            |
| `FEATURE_MY_WORLD`            | on         | My World                                       |
| `FEATURE_EVENT_CLUSTERING`    | on         | Events, Story Mode and the hourly grouping job |
| `FEATURE_PERSPECTIVES`        | on         | Perspectives (needs events)                    |
| `FEATURE_TIMELINES`           | on         | Curated timelines in Story Mode                |
| `FEATURE_JOURNEYS`            | off        | Story Journeys (needs curated journeys)        |
| `FEATURE_WORLD_PULSE`         | off        | Report counts per country on the map           |
| `FEATURE_COUNTRY_CONNECTIONS` | off        | Countries named in the same events             |
| `FEATURE_AI_SUMMARIES`        | locked off | Not implemented                                |
